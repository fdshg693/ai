# docs/ — このリポジトリのOKF知識バンドル

AIツールを問わずリポジトリ全体で参照する知識（メンテナンス規約・設計判断・運用知識）を、OKF (Open Knowledge Format) v0.2の概念ドキュメントとして整理したバンドル。

# セクション

- [repo-wide](repo-wide/) — このリポジトリ自身のメンテナンスに関する概念ドキュメント群（もと `meta-plugins/skills/` 配下のメタスキル群から移行）
- [integrations](integrations/) — このリポジトリの成果物（プラグイン・CLIツール）を自分の環境へ取り込むための導入手順群（もとリポジトリ直下の `integrations/` フォルダから移行）
- [claude_sandbox](claude_sandbox/) — `tools/sandbox`（ISSUE駆動Dockerサンドボックスエージェント）の運用中に得た調査結果・既知の不具合
