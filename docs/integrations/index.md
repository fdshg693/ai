# integrations/ — このリポジトリの成果物を自分の環境へ取り込むための導入手順

このリポジトリに存在するプラグイン・CLIツールを、AIツールを問わず自分の環境（他リポジトリ・自分のPC）に取り込むための導入手順群。もとはリポジトリ直下の `integrations/` フォルダとして分散していたが、OKF概念ドキュメントへ移行した。登録済みの skill bundle を一覧・検索・導入する `skill-tools` CLI は [tools/skill-tools/](../../tools/skill-tools/) に配置されている。

- [claude-code](claude-code.md) — Explains how to add this repository's claude-plugins/ marketplace (seiwan-marketplace) to a user's own Claude Code environment — via /plugin marketplace add (GitHub or a local clone path), installing individual plugins, and auto-provisioning teammates via .claude/settings.json's extraKnownMarketplaces/enabledPlugins. Use when installing or updating this repo's Claude Code plugins into an external environment.
- [cli-tools](cli-tools.md) — Explains how to install this repository's own CLI tools (aim, tav-cli, skill-tools, textgraph, ona-run, agents-rules) via docs/integrations/justfile's *-local (editable, for a cloned checkout) and *-git (uv tool install from a git URL, no clone needed) recipe pairs, plus how release:true packages are pinned with a git tag. Use when a skill or script fails because a prerequisite CLI isn't installed, or when deciding whether to install editable-local vs git-remote vs a pinned tag.
- [cline](cline.md) — Explains how to install this repository's cline-plugins/meta AgentPlugin globally into Cline (just cline-personal-info), and documents three Windows-specific known issues encountered along the way — PATH vs Path case-sensitivity breaking npm spawn from PowerShell/cmd, hub-daemon EADDRINUSE port conflicts, and @cline/cli-windows-x64's missing @cline/shared and jiti dependencies causing "load failed" plugins — with their workarounds. Use when `cline plugin install` fails on Windows, or when deciding whether a Cline plugin issue is this repo's code vs an upstream Cline packaging bug.
- [codex](codex.md) — Explains how to install this repository's codex-plugins/meta plugin via the .agents/plugins/marketplace.json local marketplace (seiwan-codex-marketplace) — from the ChatGPT desktop app, or from Codex CLI with or without cloning (including sparse checkout), plus update/removal commands and troubleshooting when the plugin doesn't appear. Use when installing or updating this repo's Codex plugin into an external environment.
