# my-tools-no-install

スキルから呼ばれる自作スクリプト・ツール向けの Claude Code プラグイン。

[my-tools](../my-tools/) と同じく自作ツールをスキル経由で使うが、こちらはスクリプトなどをスキルに同梱する。対応する CLI を `tools/` からインストールする必要はなく、プラグイン（または個別スキル）をよそへ移しても動く想定である。

`tools/` 配下のインストール済み CLI を前提にするスキルは [my-tools](../my-tools/) に置く。そちらはツール本体を同梱しないため、未インストール環境では使い物にならない。

## 使い分け

|            | [my-tools](../my-tools/)              | my-tools-no-install（このプラグイン）      |
| ---------- | ------------------------------------- | ------------------------------------------ |
| ツール本体 | `tools/` に置き、別途インストールする | スキルフォルダに同梱する                   |
| 前提       | PATH 上に CLI があること              | プラグイン一式があれば動く                 |
| 向き       | このリポジトリで開発・利用するとき    | プラグインだけをよそへ移しても使いたいとき |

## スキルの置き方

個別スキルは `skills/<skill-name>/` に置き、実行に必要なスクリプトもその配下へ同梱する。スキル単体（またはプラグイン一式）をコピーした先でも、リポジトリルートの `tools/` やグローバルインストールを参照しないこと。

最初のスキルは [skills/web-lookup/](skills/web-lookup/)（grep.app / Microsoft Learn / Tavily / Context7 を1つの同梱 CLI にまとめた WEB 調査）。概要は生成カタログ [skills/CATALOG.md](skills/CATALOG.md) を見る。設計意図は同階層の `README.md`、実行時の手順は `SKILL.md`。
