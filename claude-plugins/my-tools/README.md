# my-tools

スキルから呼ばれる自作スクリプト・ツール向けの Claude Code プラグイン。

対象は [`tools/`](../../tools/) 配下の CLI を、会話の中から判断付きで使うためのスキル群である。ツール本体はこのプラグインに同梱しない。各スキルは、対応するツールがあらかじめインストールされていることを前提にする。

未インストールの環境では、大半のスキルは使い物にならない。インストール不要で持ち運びたい場合は、スクリプトをスキルに同梱する [my-tools-no-install](../my-tools-no-install/) を使う。

## 使い分け

|            | my-tools（このプラグイン）            | [my-tools-no-install](../my-tools-no-install/) |
| ---------- | ------------------------------------- | ---------------------------------------------- |
| ツール本体 | `tools/` に置き、別途インストールする | スキルフォルダに同梱する                       |
| 前提       | PATH 上に CLI があること              | プラグイン一式があれば動く                     |
| 向き       | このリポジトリで開発・利用するとき    | プラグインだけをよそへ移しても使いたいとき     |

`tools/` 側の実装とスキルの役割分担（スキルは使い方と判断だけを扱い、インストールは行わない）は [docs/repo-wide/tool-companion-skills.md](../../docs/repo-wide/tool-companion-skills.md) を参照。

## スキル一覧

個別スキルは [skills/](skills/) 配下。概要は生成カタログ [skills/CATALOG.md](skills/CATALOG.md) を見る。各スキルの設計意図は、あれば同階層の `README.md`、実行時の手順は `SKILL.md`。
