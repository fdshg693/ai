# aim-cli スキルについて

`tools/aim/`の`aim` CLI（OpenRouter経由でAIモデルを単発呼び出しするツール）を、Claudeが会話の中からすぐ使えるようにするためのスキル。このファイルは人間のメンテナ向けで、設計意図と前提条件を説明する。Claudeが実行時に読むのは[SKILL.md](SKILL.md)であり、こちらは参照しない。

## なぜこのスキルがあるか

- `aim`はエージェント機能を持たない単発呼び出し専用CLI。旧独立コマンド`aim-ask`のファイル取り込み・並列実行は、独立した2機能（`@path`によるファイル取り込みと、`--parallel`による複数プロンプトの並列）としてこのCLIに取り込んだ（エイリアスは残していない）
- フラグ・デフォルトモデル・各モデルの説明は`aim --ai-help`が正本なので、スキルに複製しない
- 前提条件が満たされないときの案内、ログの意味論、`@path`/`--parallel`と`aim-summarize`の分岐など、`--ai-help`だけでは固定されない運用判断をスキルに置く

## 前提条件（重要）

- `aim`コマンドは事前にインストール済みであること（`uv tool install --editable tools/aim`）。このスキルはインストール処理を一切行わず、CLI本体も同梱しない
- `OPENROUTER_API_KEY`が環境変数または`tools/aim/.env`で設定済みであること
- 上記が満たされていない環境（未インストール・APIキー未設定）でこのスキルが呼ばれた場合、Claudeはこのスキルではエラーに対処せず、`tools/aim/README.md`のセットアップ手順をユーザーに案内する

## 情報源と保守

- CLIオプション・ログ形式・エラー挙動の一次情報は`tools/aim/README.md`
- 略記・モデルID・デフォルト・各モデルの説明は`tools/aim/models.json`がSSOT。SKILL.mdに一覧表やフラグ表を複製しない。エージェントには`aim --ai-help`を実行させる（人間向けは`aim --help`）。`@path`/`--parallel`の最小のコマンド形は判断節に置いてよい
- SKILL.mdは判断（前提条件、ログ/エラーの意味論、`@path`/`--parallel`と`aim-summarize`の分岐）だけを持ち、フラグやモデル選定の文章説明は`--ai-help`に任せる。フラグ表は復活させない

二重化した内容のドリフトを防ぐため、CLI仕様を変更するときは次の順で確認する。

1. `tools/aim/README.md`を正本として、CLI本体と仕様を更新する
2. モデルの追加・改名・有効/無効（`enable`）・デフォルト変更・説明の更新は`tools/aim/models.json`だけを編集し、SKILL.mdに転記しない
3. `aim --ai-help`と`SKILL.md`の判断節（前提条件、ファイル取り込みと並列、`--cost`、ログ、エラー時の挙動）が同じ変更内容に追従しているか確認する（使い方本文は`--ai-help`側）
