# aim2-cli スキルについて

`tools/aim2/` の `aim2` CLI（複数プロバイダ対応 AI モデル単発呼び出しツール）を、Claude や各種エージェントが会話の中から迅速に使えるようにするためのコンパニオンスキル。このファイルは人間のメンテナ向けで、設計意図と前提条件を説明する。実行時に読むのは [SKILL.md](SKILL.md) であり、こちらは参照しない。

## なぜこのスキルがあるか

- `aim2` はエージェント機能を持たない軽量 CLI。OpenAI, Anthropic, Google Gemini, OpenRouter, Ollama に直接対応し、`--session-id` によるローカルログベースの会話継続だけを持つ（`--thread-id` は互換エイリアス）
- フラグ・デフォルトモデル・各モデルの説明は `aim2 --ai-help` が正本なので、スキル本文にモデル一覧やオプション表を複製・二重管理しない
- 前提条件が満たされないときの案内、ログ・エラーの正規化意味論、`@path`/`--parallel` の分離、`session_id` と `trace_id` の役割分離など、`--ai-help` だけでは固定されない運用判断をスキルに置く

## 前提条件

- `aim2` コマンドは事前にインストール済みであること（`cd tools/aim2 && pnpm add -g .`）
- 利用プロバイダの API キーが環境変数または `tools/aim2/.env` で設定済みであること（Ollama はローカルのため不要）
- 未インストール・未設定の場合はこのスキルでは対処せず、`tools/aim2/README.md` のセットアップ手順を案内する

## 保守

二重化した内容のドリフトを防ぐため、CLI 仕様を変更するときは次の順で確認する。

1. `tools/aim2/README.md` を正本として、CLI 本体と仕様を更新する
2. モデルの追加・変更は `tools/aim2/models.json` だけを編集し、SKILL.md に転記しない
3. `aim2 --ai-help` と `SKILL.md` の判断節（前提条件、並列、ログ、`--session-id`/`--thread-id`、エラー）が整合していることを確認する
