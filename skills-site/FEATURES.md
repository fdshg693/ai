# 機能一覧（ユーザー視点）

このドキュメントは、公開サイト「スキルカタログ」を訪れたユーザーが実際に何をできるかをまとめたものです。実装の詳細（生成スクリプトやカタログのデータ構造など）は扱いません。ソースと成果物の対応は [README.md](README.md) を参照してください。

## トップページ（一覧）

- 登録されている全スキルをカード形式で一覧表示します。1件のスキルにつき、対象AIツール名・プラグイン名・スキル名・説明文・ステータスバッジ・リポジトリ上のパスが表示されます。
- 収録スキル数がヒーローエリアに表示されます。

### 絞り込み・検索

- **スキル名で検索**：テキスト欄にキーワードを入力すると、スキル名・説明文を対象にした全文検索が働き、該当するスキルだけが表示されます（サーバー側API `/api/search` による検索。ローカル開発でAPIが動いていない場合はスキル名の部分一致検索にフォールバックします）。
- **AIツールで絞り込み**：ドロップダウンから対象のAIツール（例: Claude Code、Codex など）を選ぶと、そのツール向けのスキルだけが表示されます。
- **プラグインで絞り込み**：ドロップダウンから特定のプラグインを選ぶと、そのプラグインに含まれるスキルだけが表示されます。
  - ツールを先に選ぶと、プラグインの選択肢はそのツールに存在するものだけに自動的に絞り込まれます（存在しない組み合わせは選べません）。
- **ステータスで絞り込み**：ドロップダウンからステータス（ステータス未設定 / Draft / Experimental / Stable / 非推奨 / 未定義）を選ぶと、そのステータスのスキルだけが表示されます。選択肢は実際に存在するステータスのみが表示されます。
- キーワード検索・ツール・プラグイン・ステータスは同時に指定でき、すべての条件を満たすスキルだけが表示されます。
- 「条件をリセット」ボタンで絞り込みを解除し、全件表示に戻せます。
- 現在の絞り込み条件で何件のスキルが表示されているかがリアルタイムに表示されます。
- 絞り込み結果が0件のときは「条件に一致するスキルはありません。」というメッセージが表示されます。
- 絞り込みはページを再読み込みせずブラウザ内で即座に反映されます。

### AIによるスキル提案（任意機能）

- 「AIにスキルを提案してもらう」パネルを開き、自然文で質問（例:「テストを書くときに使えるスキルは？」）すると、サーバーが埋め込み類似度で候補を最大10件に絞ったうえで AI（LLM）が関連スキルを最大5件挙げ、各詳細ページへのリンクと理由（日本語1文）とともに表示します。
- APIキーの入力は不要です。問い合わせはブラウザからサーバー側API（`/api/suggest`）に送られ、サーバーが保持するOpenRouter APIキーでOpenRouterを呼び出します。ユーザーのAPIキーを入力・保存させる仕組み（BYOK）は提供していません。
- 利用するチャットモデルはサーバー側で固定（`minimax/minimax-m3`）です。ブラウザからモデルを選ぶUIはありません。
- 過度な呼び出しを防ぐため、サーバー側でレート制限があります。制限に達した場合や、サーバー側でAPIキーが未設定などの理由で機能が利用できない場合は、その旨のメッセージがパネルに表示されます。
- これはサイトが自動で行うレコメンド機能ではなく、ユーザーが都度呼び出す任意加入のAI機能です。

## スキル詳細ページ

一覧のカード、または詳細ページへのリンクから、各スキルの詳細ページに遷移できます。

- **本文**：スキルの `SKILL.md` の内容がMarkdownとして整形表示されます（見出し・リスト・表・コードブロック・リンクなどに対応）。
- **説明文**：
  - AIがこのスキルを起動するかどうかを判定するための説明文（`description`）。
  - 人間向けの補足説明が別途設定されている場合は、それも並べて表示されます。
- **メタデータ**：対象AIツール、プラグイン名、スキル名、ステータス、バージョンを確認できます。
- **リポジトリ上のパス**：このスキルがリポジトリのどこにあるかを確認できます。
- **依存関係・詳細メタデータ**：
  - このスキルが前提とする他のスキル（登録済みのものは詳細ページへのリンク付き）。
  - このスキルが前提とするフックの説明（外部ドキュメントへのリンク）。
  - このスキルが必要とするリポジトリ内ツールの一覧（外部リンクがあればそちらへ）。
  - 未設定の項目は「なし」と表示され、項目自体は常に表示されるため、複数スキルを見比べやすくなっています。
- **同梱ファイル一覧**：ダウンロードされるZIPに含まれる全ファイルのパスとファイルサイズを一覧で確認できます。
- **ZIPダウンロード**：スキルフォルダ一式をZIPファイルとしてその場でダウンロードできます。
- パンくずリストと「一覧へ戻る」リンクで一覧ページに戻れます。

### ステータス表示

各スキルには以下のいずれかのステータスバッジが付き、成熟度がひと目でわかります。

| バッジ           | 意味                                 |
| ---------------- | ------------------------------------ |
| ステータス未設定 | 通常のスキルとして掲載               |
| Draft            | 作成中の下書き                       |
| Experimental     | 試験的なスキル                       |
| Stable           | 安定版として推奨                     |
| 非推奨           | 利用は推奨されない                   |
| 未定義: `<値>`   | 想定外のステータス値が設定されている |

## 共通UI

- 全ページ共通のヘッダー（サイトトップへのリンク、GitHubリポジトリへのリンク）とフッターを備えます。
- 各ページにタイトル・説明文・canonical URLが設定され、検索エンジンやSNSでの表示に対応します。

## 現時点で提供していない機能

- スキル本文（SKILL.mdの内容）まで対象にした全文検索（現状はスキル名・説明文が検索対象です）。
- ログインやお気に入り登録などのユーザーアカウント機能。
- アクセス解析、およびサイト側が自動で行うレコメンド機能（ユーザーの質問に対して都度呼び出すAI提案機能は上記の通り提供）。
